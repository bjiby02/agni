# Archived Ares engine

This folder holds the earlier Ares "phone line that decides" app (stdlib `http.server`, its own console and voice loop). AGNI does not run it. The plan says to copy only the bearing, geography and feed helpers, and those now live in `backend/core/` (`swarm.py`, `geo.py`, `feeds.py`, `directory.py`).

Kept for reference only. Nothing in `backend/` or `frontend/` imports from here.
